## 📚 Document RAG Agent (`rag_agent.py`)

Retrieves records from [students.csv](file:///c:/Users/vel%20prakash%20s/OneDrive/Documents/calculator/students.csv) (25 student records) with precision.

### How to Run:
```powershell
python rag_agent.py
```

### Quick Commands in RAG CLI:
- **`questions`**: Lists all 10 suggested questions from the document.
- **`test_all`**: Runs all 10 suggested questions in sequence.
- **`1` to `10`**: Runs a specific question instantly by number.
- Or type any natural language question!
